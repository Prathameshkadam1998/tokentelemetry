THREE DIFFERENT MEASUREMENTS

Tokens are not a fuel gauge.

Historical usage
Measured tokens processed over past requests. They accumulate; they do not drain a local Ollama allowance.
Context capacity
The window available to one request. Last prompt size is not live occupancy, and the server can override requested settings.
Provider limits
Only source-reported plan windows appear below agent accounting. No provider quota is inferred for a local model.

First connection & troubleshooting
  1. Enable Remote Login on the Mac if you choose SSH. From PowerShell, connect with ssh your-user@mac-mini.local and verify its host key yourself. Set up SSH key authentication so future connections do not require a password.
  2. Keep Ollama running on the Mac. SSH mode uses its existing loopback endpoint; no Ollama network binding or firewall change is needed.
  3. Enter that SSH destination above, then save. If the tunnel exits or a port is busy, resolve the cause and use Save & reconnect.
  4. To measure tokens, configure the application making requests to use the proxy URL above. Requests made directly on the Mac remain outside this ledger.

The app does not accept unknown SSH keys or store passwords. Direct endpoints must be HTTP(S) origins without paths or embedded credentials. GPU utilization and live context occupancy remain unavailable.
